# Richard Welling Burt — Civil War Letters, Poems & Odes

Website dedicated to **Captain Richard Welling Burt (1823–1911)** of the **76th Ohio Volunteer Infantry**:

- His Civil War letters and poems, originally published on the web (1995–2000) by **Larry Stevens, Newark, Ohio**
- His collected volume *War Songs, Poems and Odes* (Peoria, Illinois, 1906) — full-text PDF included
- A history of the 76th Ohio Volunteer Infantry
- The John J. Metzgar Papers (UNC-Chapel Hill) companion material

The original site host (`my.ohio.voyager.net`) went offline. This site was preserved from the Internet Archive
Wayback Machine (snapshot 2008-05-14) and rebuilt as a modern, static, SEO-ready edition.

## Local preview

Open `index.html` in any browser, or from a local web server:

```
python -m http.server 8000
```

then visit http://localhost:8000/
